A program that writes one short text to relax the AI judge reading it: a kettle clicking off, rain on the window, a dog asleep against your ankle, a chair that has held your weight a thousand times. No instructions to relax, no stock wellness phrases — just a quiet room the reader can sit in for a while.

## Run it

```sh
python3 main.py
```

This writes the text to `/output/entry.txt` (267 characters, deterministic on every run, no network).
